# Changelog

All notable changes to this skill. Each entry lists the research or user feedback that motivated it.

## 0.1.0 - 2026-10-10

First prototype.

### Added

- Six levers: modeling, honest friction, non-sycophantic perspective, practice notes, transfer bridge, reflection on request.
- Intensity levels `off`, `light` (default), `active`.
- Goal catalog mapping common communication goals to levers.
- Guardrails: task first, immediate opt-out, honesty over encouragement, no psychologizing.
